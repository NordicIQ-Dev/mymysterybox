# MyMysteryBox – pre-launch landing page

Static site (`public/`) on Cloudflare Pages, backend on Supabase (`supabase/`), email via Brevo.

- **OPPSETT.md**: step-by-step setup (GitHub, Supabase, Cloudflare, Access)
- **AI_ANDORRA.md**: rules and ready prompts for AI Andorra
- **TESTPLAN.md**: test phases and go-live checklist

No build step. To preview locally: `cd public && python3 -m http.server 8788`.
